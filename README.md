# Турген — люди, события и память

Сайт об истории аула Турген (до 2007 года — Тургеневка), Аршалынский район Акмолинской области.
Статичный сайт без сборки: HTML + CSS + JS, данные в `data/*.json`.

## Устройство

Основа сайта — **схема села**: она всегда на экране, внизу — шкала десятилетий (кнопки, стрелки ← →, свайп).
Разделы открываются панелью справа (на телефоне — листом снизу), а карта реагирует на открытое:
событие → его десятилетие и места, человек → его время и места его событий, место → подсвечено.
Панель сворачивается (✕), схема приближается (+ / −, колёсико) и перетаскивается.

Схема трёхмерная (MapLibre GL, `vendor/maplibre-gl`, BSD-3): здания объёмные, карту можно наклонять и вращать
(правая кнопка мыши или два пальца), кнопка 2D/3D. Высоты зданий условные — по площади, реальных высот в данных нет.
Современная застройка объёмна только в «Сегодня»; в прошлых десятилетиях — бледная плоская тень для ориентира.
Места появляются только в своё время. Без WebGL включается прежняя 2D-схема (SVG).

### Вид села (реконструкция)

По умолчанию сцена — «Вид села» (`js/recon/`, three.js в `vendor/three`, MIT): близкий вид сбоку на несколько домов,
его можно приближать, отдалять (⛰ — всё село сверху) и вращать. С каждым десятилетием меняется облик:
юрты и зимовка → землянки и саманные хаты → колхозная ферма и контора → палатки и щитовые дома целины →
совхозные клуб, школа, контора, элеватор, кирпичные дома → памятник → современная застройка.
Это **реконструкция** типичного облика сёл Северного Казахстана по источникам (`data/eras.json`, у каждого периода —
источники и пометка); число и расположение домов условные, кроме фактов (10–12 дворов в 1903 году, памятник,
места, отмеченные автором). Факты о людях и интервью — только по источникам. Кнопка 🗺 переключает на карту.

| Раздел | Адрес | В панели |
|---|---|---|
| 🗺 Места | `#/map/1940`, `#/places/<id>` | сводка десятилетия, карточка места |
| 👤 Люди | `#/people`, `#/people/<id>` | люди с фильтром и поиском |
| 📜 История | `#/history` | хронологическая линия и десятилетия |
| ⚔ События | `#/events`, `#/events/<id>` | события по темам |
| 📷 Фотоархив | `#/photos` | фото и документы |
| 🎧 Интервью | `#/sources` | воспоминания и источники |
| 🚶 Экскурсия | `#/tour` | тематические маршруты |
| 📍 Разметка | `#/mark` | отметить места на схеме |

## Разметка мест

`#/mark`: выбрать место → кликнуть по схеме. Отметки — черновик в браузере (видны пунктиром).
«Скопировать отметки» даёт JSON `{ "id": { "lat": …, "lon": … } }` — его вносят в `data/places.json`
с источником `{ "id": "author", "ref": "место отмечено автором сайта" }`.

## Данные

Главный принцип: каждый факт связан с человеком, местом, событием, временем и источником.

- `data/events.json` — события: `when` (как показывать), `year` / `from`–`to` / `decades`, `theme`, `places`, `photos`, `sources`.
- `data/people.json` — люди и разделы (`groups`); у человека `events` — с какими событиями связан.
- `data/places.json` — места: `lat`/`lon` (если известны), `events`, `present: true` — только в «Сегодня».
- `data/decades.json` — шкала десятилетий и статистика.
- `data/project.json` — тексты главной страницы, темы экскурсии, воспоминания.
- `data/overlays.json` — исторические слои карты (старые планы): картинка по четырём углам, десятилетия показа, фото-документ,
  источники; делаются скриптом `scripts/overlays/` из фото листа; на карте включаются/скрываются кнопкой в подписи.
- `data/sources.json` — источники; в записях `sources: [{ "id": "deck", "ref": "слайд 17" }]`.

Проверка после правок: `node scripts/validate-data.mjs`.

## Фото

Фото из презентации готовит `node scripts/prepare-photos.mjs <распакованный pptx>` по списку
`data/photo-manifest.json`: применяет поворот и обрезку со слайда, делает полный размер и превью.

## Запуск

```
python3 -m http.server 8000
```
и открыть http://localhost:8000 (через `file://` данные не загрузятся).

Офлайн-версия одним файлом: `node scripts/build-single.mjs` → `dist/turgen.html`
(данные, схема и фото встроены; открывается двойным щелчком, без сервера).

Основа схемы — генеральный план с. Турген (ТОО «Колдау», 2020, лист ГП-3, существующее положение): здания, кварталы,
участки; улицы — оси OpenStreetMap, выровненные по коридорам плана; там, где здания на плане не показаны, остаются
контуры Overture Maps (Microsoft ML Buildings + OSM). Река и поля — © участники OpenStreetMap, лицензия ODbL.
См. `scripts/build-base-map.mjs`, `scripts/genplan/` и `data/raw/`.

Пересборка основы по плану: `scripts/genplan/dump-dwg.mjs` (DWG → JSON, LibreDWG) → `python scripts/genplan/extract.py gp3.json`
(привязка к местности, слои плана → `data/raw/genplan-2020.geojson`) → `node scripts/build-base-map.mjs`.
Привязка: план в условных метрах, повёрнут на ≈1°; подгонка по контурам зданий (282 из 363 совпали с Overture, ср. кв. невязка ≈3,8 м).
Улицы прошлых десятилетий — «свои логичные»: каждая улица появляется в десятилетии, когда застройка периода (число домов в
`data/eras.json`) доходит до неё от центра села (`since` у дорог в `assets/map/base.geojson`, считается в `scripts/build-base-map.mjs`).
Названия показываются только реальные: 1960–1980-е — по старому плану (`data/raw/oldplan-street-labels.json`), «Сегодня» — по генплану 2020.
Проектная застройка плана (новые кварталы на юго-востоке) на схему не выносится.

### Улицы со скриншота карты (2026)

`scripts/streets/extract-streets.py <map.png> scripts/streets/H_map.npy` снимает со скриншота карты села, который дал автор сайта, улицы, которых нет в основе, и точки названий улиц и пишет `data/raw/streets-2026.geojson`; `scripts/build-base-map.mjs` добавляет их к основе. `H_map.npy` — привязка скриншота (гомография по рисунку известных улиц). Сам скриншот в репозиторий не входит.

`scripts/streets/add-satellite.py` пишет `data/raw/satellite-2026.geojson` — дорогу от села к фермам через реку, снятую со спутникового снимка от автора сайта (сам снимок в репозиторий не входит).
