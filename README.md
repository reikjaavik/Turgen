# Турген — люди, события и память

Сайт об истории аула Турген (до 2007 года — Тургеневка), Аршалынский район Акмолинской области.
Статичный сайт без сборки: HTML + CSS + JS, данные в `data/*.json`.

## Разделы

| Раздел | Адрес | Что показывает |
|---|---|---|
| 🗺 Места | `#/map/1940` | схема аула по десятилетиям; `?edit` — режим разметки координат |
| 👤 Люди | `#/people`, `#/people/<id>` | карточки людей с фильтром по разделам и поиском |
| 📜 История | `#/history` | хронологическая линия и сведения по десятилетиям |
| ⚔ События | `#/events`, `#/events/<id>` | события по темам, люди и места события |
| 📷 Фотоархив | `#/photos` | все фото и документы с подписью и источником |
| 🎧 Интервью | `#/sources` | воспоминания, интервью, список источников |
| 🚶 Экскурсия | `#/tour` | тематические маршруты по событиям |

## Данные

Главный принцип: каждый факт связан с человеком, местом, событием, временем и источником.

- `data/events.json` — события: `when` (как показывать), `year` / `from`–`to` / `decades`, `theme`, `places`, `photos`, `sources`.
- `data/people.json` — люди и разделы (`groups`); у человека `events` — с какими событиями связан.
- `data/places.json` — места: `lat`/`lon` (если известны), `events`, `present: true` — только в «Сегодня».
- `data/decades.json` — шкала десятилетий и статистика.
- `data/project.json` — тексты главной страницы, темы экскурсии, воспоминания.
- `data/sources.json` — источники; в записях `sources: [{ "id": "deck", "ref": "слайд 17" }]`.

Проверка после правок: `node scripts/validate-data.mjs`.

## Фото

Фото из презентации готовит `node scripts/prepare-photos.mjs <распакованный pptx>` по списку
`data/photo-manifest.json`: применяет поворот и обрезку со слайда, делает полный размер и превью.

## Запуск

```
python3 -m http.server 8000
```
и открыть http://localhost:8000 (через `file://` данные не загрузятся).

Офлайн-версия одним файлом: `node scripts/build-single.mjs` → `dist/turgen.html`
(данные, схема и фото встроены; открывается двойным щелчком, без сервера).

Основа схемы — © участники OpenStreetMap (ODbL), см. `scripts/build-base-map.mjs`.
